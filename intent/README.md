# intent/

Design intent for MobileScan. `README.md` in the repository root is the product spec;
this directory records decisions and per-version definitions.

| File | Content |
|---|---|
| `2026-09-22-spec-assessment-and-decisions.md` | Gap assessment of the spec and the decisions taken |
| `v0.1-mvp.md` | Capture + share: start, camera with frame, captured view, share sheet, PDF, PWA shell, deploy |
| `v0.2-crop-rotate.md` | Edit submenu, crop mode, fine rotation, 90-degree steps, rotation baking |
| `v0.3-brightness-contrast.md` | Brightness/contrast view with live preview and confirm |
| `v0.4-ui-polish.md` | Error states, busy states, history integration, transitions, accessibility, maskable icon, final icon set |
| `v0.5-multi-page.md` | Multi-page PDFs: [+] button, page header with navigation, parked pages, multi-page share |
| `v0.6-loupes.md` | Magnified corner previews (loupes) while dragging in the crop/rotate view |
| `v0.7-shear.md` | Shear mode: independent frame corners, perspective correction baked on confirm |
| `v0.8-auto-detect.md` | Auto buttons: paper edge detection near the frame, black-and-white auto levels |
| `v0.9-zoom.md` | Pinch zoom and pan on the image in the captured and edit views, view state only |
| `v0.10-live-detect.md` | Live document detection in the camera view: green outline, auto-bake of the perspective on capture, toggle next to the shutter |
| `v0.11-share-jpeg.md` | Share a single page as a JPEG: share popover (PDF \| image) with one page, same sheet and compression levels; popovers anchored above their buttons |
| `v0.12-frozen-still.md` | The still of the green moment: grabbed when the outline turns green, used by a shutter pressed within 600 ms while the document has not moved; shutter on the press |
| `v1.0.1-install.md` | Install button on the start page: Chrome's install prompt on Android, a help card with the share sheet route on iOS, nothing while installed |
| `v1.1-din-completion.md` | Pages in a spiral block: with three edges found the fourth is inferred from the DIN A ratio, inside the band only; behind a session flag |
| `v1.2-wide-lens.md` | Wide-angle lens switch left of the shutter: zoom range below 1 on Android Chrome, second rear device on iOS, hidden where neither exists; session state |
| `icons/` | The icon set (24x24 stroke SVGs) and the app icon. Intended to be used verbatim in the app. |
| `mockups/` | Phone-screen mockups per version, generated by `mockups/generate.py` |

Regenerate icons and mockups with `python3 intent/mockups/generate.py`.

## Version roadmap

```
v0.1 MVP  ──▶  v0.2 crop/rotate  ──▶  v0.3 brightness/contrast  ──▶  v0.4 UI polish
capture+share    edit submenu             second edit view             production quality

v0.5 multi-page  ──▶  v0.6 loupes  ──▶  v0.7 shear  ──▶  v0.8 auto-detect  ──▶  v0.9 zoom
[+] and page nav      drag previews      perspective      wand buttons           pinch on the image

v0.10 live detect  ──▶  v0.11 share as JPEG  ──▶  v0.12 frozen still
green outline in the camera, auto-bake on capture    PDF | image popover with one page    the still of the green moment
```

Second roadmap added 2026-09-22 (decisions in `2026-09-22-spec-assessment-and-decisions.md`,
section "v0.5 to v0.8 decisions"). v0.9 added 2026-09-22 after the viewport fix of v0.6
removed the accidental page zoom (section "v0.9 decisions"). v0.10 added 2026-09-22 from a
user request for document detection in the camera view (section "v0.10 decisions"). v0.11 added
2026-09-23 from a user request to share a single page as an image (section "v0.11 decisions").
v0.12 added 2026-09-23 after device use showed that the press in reaction to the green outline
moves the phone (section "v0.12 decisions"). v1.0.1 added 2026-09-23 from a user request for an
install button on the start page. v1.1 added 2026-09-23 from a user request for pages in a
spiral block, whose bound edge the detection never finds (section "v1.1 decisions"). v1.2 added
2026-09-23 from a user request to reach the phone's 0.5x lens while aiming (section "v1.2
decisions"); planned, not yet implemented.

Each version is independently deployable to https://mobilescan.app and leaves the app usable.
