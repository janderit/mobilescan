# v0.11 Share a single page as a JPEG

## Goal

Some targets want a picture, not a document: a chat, a form that accepts only images, a
photo library. With one scanned page the share button therefore asks first whether the page
goes out as a PDF or as an image, and then continues with the same share sheet, so the
compression level applies to the JPEG too. With several pages nothing changes: they can only
be one PDF.

While adding the second popover, the first one is put where it belongs: the edit popover was
positioned at a fixed offset from the right edge of the screen, right for the three-button bar
of v0.2, but above [+] since v0.5 added the fourth button. Both popovers are now anchored above
the button that opened them.

## Scope

In:
- Share popover: with exactly one page, the share button opens a popover above itself, in the
  style of the edit popover, with two compact icon buttons: `document` ("Als PDF teilen") and
  `image` ("Als Bild teilen"). A tap on the backdrop, a second tap on the share button or
  hardware back closes it. Either item closes the popover and opens the share sheet.
- Share sheet: unchanged (three levels, cancel, confirm). Confirm builds the PDF or, for the
  image choice, the JPEG of the current page's frame region at the level's quality, and hands
  it to the Web Share API (download fallback as before).
- Several pages: the share button opens the sheet for the PDF directly, without the popover.
- Popover anchoring: the captured view measures the opening button on every render while the
  popover is open and writes the button's centre (relative to the screen) to `--anchor-x` on
  the popover; the CSS centres the popover and its tip on it (`left: var(--anchor-x)`,
  `translate: -50% 0`, `transform-origin: 50% 100%` so the pop-in scales from the tip).

Out: several images in one share (multi-file share), PNG or other formats, a remembered
format choice (no persistence), an image option in the multi-page case, changes to the PDF.

## Behaviour

1. Share tap, one page: the popover toggles (`shareMenuOpen`). The share button carries
   `aria-expanded`. Nothing else on the screen reacts while it is open (backdrop).
2. Share tap, two or more pages: the sheet opens with the format `pdf`, as in v0.5.
3. Popover item: sets the format (`pdf` | `jpeg`), closes the popover, resets the level to the
   default and opens the sheet.
4. Confirm: behind the busy overlay, `buildPdfFile` for `pdf`, `buildJpegFile(currentPage)` for
   `jpeg`. The JPEG is the frame region rendered like a PDF page image, `encodeJpegBlob` at
   `jpegQuality(level)`, a `File` named `scan-YYYYMMDD-HHMMSS.jpg` of type `image/jpeg`. The
   share title stays "Scan".
5. Outcome as for the PDF: shared → start page, pages discarded; aborted → captured view with
   the sheet closed; failure → notice "Teilen fehlgeschlagen", sheet closed.
6. The format is reset to `pdf` implicitly: every path into the sheet sets it. It is never
   stored.
7. Back (hardware or popstate) with the popover open closes the popover only; back from the
   captured view, [+] and every screen change close it like the sheet and the edit popover.
   A page swipe cannot happen while it is open (one page only).

## Data model changes

`ShareFormat = 'pdf' | 'jpeg'` in `src/model.ts`; `shareMenuOpen` and `format` in the app
state. `src/share.ts`: `buildJpegFile(page, level)`, `sharePdf` renamed to `shareFile`.
`src/pdf.ts`: `scanFileName(date, extension)` behind `pdfFileName`. `src/captured-view.ts`:
a second popover, both built by one helper and anchored on render. No stored data.

## Icons used

New: `document` (share as PDF), `image` (share as JPEG), in `intent/icons/` and
`src/icons.ts`. Existing: `share`, the file icons of the sheet.

## Acceptance criteria

- Unit test (jsdom, app shell): with one page, share opens the popover and not the sheet, and a
  second tap closes it; the image item opens the sheet and confirm hands a `File` of type
  `image/jpeg` named `scan-…jpg` to `navigator.share` with the chosen level's quality, after
  which the app is on the start page with no pages; the PDF item shares a PDF as before.
- Unit test: with two pages, share opens the sheet directly and shares a PDF.
- Unit test: hardware back and a backdrop tap close the popover and keep the page; an aborted
  image share keeps the page and closes the sheet.
- On the phone: the edit popover sits above the edit button, the share popover above the share
  button, each with its tip on the button; the pop-in grows from the tip. Sharing a page as an
  image to a chat app delivers a JPEG whose size changes with the level.
